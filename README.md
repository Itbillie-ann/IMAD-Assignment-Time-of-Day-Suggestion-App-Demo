AutoTimeResponder

This is a simple Android app that gives automatic suggestions based on the time of day. 
You type things like “morning”, “afternoon”, or “night” and it shows a little message on what you could do.

How to use

-Open the app.

-Type a time of day in the box.

-Press Get Suggestion to see the suggestion.

-Press Reset to clear the input and start again.

What it does

-Morning → “Send a 'Good morning' text to a family member.”

-Afternoon → “Share a funny meme or interesting link with a friend.”

-Night → “Leave a thoughtful comment on a friend's post.”

Tech stuff

1. Built with Kotlin in Android Studio.
   
2. Uses EditText, Button, and TextView.
   
3. Handles edge-to-edge display properly on phones.
